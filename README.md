# Notası

Yetişkinlerin nota okumayı öğrenmesi ve ney çalmaya başlaması için hazırlanmış, Türkçe arayüzlü bir ilerleyici web uygulaması (PWA). Gündüz kısa dersler, akşam ney çalışması sunar. Tüm kullanıcı verisi cihazda kalır.

## Çalıştırma

```sh
npm install
npm run dev      # geliştirme sunucusu
npm test         # testleri çalıştırır
npm run build    # üretim derlemesi (dist/)
```

Node.js 24 ile geliştirilmiştir.
